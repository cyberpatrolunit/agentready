# Free sample skill

`codebase-tour` is one of the 12 workflow skills from the
[Agent-Ready Pro Pack](https://getagentready.dev/#pro), released free.

Install into any repo:

```sh
mkdir -p .claude/skills
cp -r codebase-tour /path/to/your-repo/.claude/skills/
```

Claude Code picks it up automatically — ask for a codebase tour, or let it
trigger when you ask "how does X work here?".

The other 11 (code review, TDD, systematic debugging, safe refactoring,
release checklists, DB migrations, and more) are in the
[Pro Pack](https://getagentready.dev/#pro).
